# BuildCore – Construction Website (React + Tailwind + Vite)

## Run
1. Install Node.js 18+ (https://nodejs.org)
2. `npm install`
3. `npm run dev`  → open http://localhost:5173
4. `npm run build` for production (output in /dist)

## Customize
- Company name, text, services, projects: `src/App.jsx`
- Colors and fonts: `tailwind.config.js`
- Images: replace the Unsplash IDs in the `IMG` object with your own photos (put files in /public and use "/photo.jpg")
